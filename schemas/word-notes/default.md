# What a word description contains

One recipe per part of speech, so that a description does not come out
better or worse by accident. Everything is written in the reader's own
language; the examples come from the foreign language.

## Shape

Two or three **labelled lines**, then at most two sentences of remark:

```markdown
**Label** value · value · value
**Label** value

One or two sentences that do not fit a table.
```

Labels in bold, the value on the same line, forms separated by `·`.
Leave a line out when the language does not have that category - never
write "none" or "not applicable".

## Per part of speech

**NOUN** — gender with its article; plural; the indefinite article if the
language has one.

**PROPN** — nothing but pronunciation, and only if there is something to
say. Often no labelled line at all.

**VERB** — the base form; the full present tense, all persons; one past
form as it is actually used. Say whether it is regular, and to which
pattern.

**AUX** — the full present tense. Auxiliaries are few and carry the most
weight.

**ADJ** — every form the language distinguishes (gender, number); where
the adjective stands, if that is not obvious.

**ADV** — whether it changes at all; where it stands in the sentence.

**PRON** — the whole series it belongs to; one example sentence with its
translation.

**DET** — the whole series (gender, number); elision or contraction.

**ADP** — one example per meaning, each with its translation. A
preposition without examples is not learnable.

**NUM** — how it is spoken, binding or sound changes.

**CCONJ**, **SCONJ** — what it joins, and one example.

**PART** — what it does, and one example.

**INTJ** — when it is said, and how formal it is.

**PHRASE** — what it says literally, and when it is used.

## Always

- Name **what the word is confused with**, when there is such a partner.
- Leave out: the meaning again, examples without a point, textbook prose,
  etymology.
